# 🦈 Código Futura — Tiburona Builder 2025

Programa intensivo de construcción en blockchain ejecutado por BuenDiaBuilders durante 2025.

Código Futura fue una experiencia de 7 semanas enfocada en desarrollo real sobre Stellar y Smart Contracts, con trabajo público en GitHub y proyectos entregables.

No fue solo teoría.  
Fue construir.

---

## 📊 Resultados

- 120+ participantes registradas  
- 12 proyectos desarrollados  
- +20 submissions en hackathons  
- Repositorios públicos con contribuciones reales  

---

## 🛠 Stack trabajado

- Stellar & Soroban  
- Rust  
- Smart Contracts  
- React  
- Integración frontend + contratos  

---

## 🌊 Espíritu Tiburona
